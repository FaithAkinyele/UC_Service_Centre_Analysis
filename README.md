\# UC Service Centre Analysis



\## Project Overview



This project is a simulated data analysis exercise based on the operations of fictional Universal Credit service centres.



The project uses Excel, SQL Server and Power BI to examine service-centre performance, claims processing, customer contacts, caseloads and staffing. It demonstrates an end-to-end analytical process, from inspecting and cleaning source data to performing analysis, validating results and presenting findings through an interactive dashboard.



\## Project Objectives



The objectives of this project are to:



\- inspect and understand the supplied Excel datasets;

\- identify and resolve data-quality issues;

\- load and transform the data using SQL Server;

\- analyse operational performance and service outcomes;

\- create quality-assurance checks;

\- build an interactive Power BI dashboard;

\- document the analytical process and key findings.
